# الحكيم للمحاسبة

نظام إدارة مخزون ومبيعات لمحل اتصالات، مبني بـ Flutter.

## النسخة الحالية
- لوحة تحكم عربية RTL.
- إدارة المنتجات وإضافة/تعديل/حذف.
- سعر شراء وسعر بيع وكمية.
- دعم الباركود مع فهرس سريع داخل SQLite.
- مسح الباركود بالكاميرا.
- إذا كان الباركود موجودًا: يعرض السعر والكمية.
- إذا كان غير موجود: يفتح إضافة المنتج مع الباركود المقروء.
- تصوير المنتج بالكاميرا وحفظ مسار الصورة محليًا.
- بحث بالاسم والباركود والماركة والموديل.
- قيمة المخزون وتنبيه المنتجات منخفضة الكمية.
- قاعدة بيانات محلية SQLite قابلة للتوسع.

## تشغيل المشروع

يتطلب Flutter SDK متوافقًا مع Dart 3.4+.

```bash
flutter pub get
flutter run
```

لإخراج APK:

```bash
flutter build apk --release
```
